# 🐉 Dragon Game

A simple browser-based game built using HTML, CSS, and JavaScript where you control a dragon and avoid obstacles.

---

## 🎮 How to Play

* Press **Space** (or Arrow Up) to jump
* Press **A** & **D** (or Arrow Left or Arrow Right) to move left and right
* Avoid hitting obstacles
* Survive as long as possible to get a higher score
